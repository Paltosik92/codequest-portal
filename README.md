# CodeQuest

**От первой строки кода до собственного проекта.**

Личная библиотека практических курсов по программированию. Пять направлений, единый интерфейс, индивидуальные обложки и шаблон для длинных Markdown-методичек. Язык — русский, тёмная тема по умолчанию, светлая включается кнопкой в шапке.

Сайт работает на Astro, TypeScript и CSS, собирается в статический HTML. React, Vue, база данных, авторизация и платные сервисы не используются. Внешних шрифтов, аналитики и удалённых картинок нет.

## Локальный запуск

Требуется Node.js 24 LTS и npm. Выполняйте команды **из папки `codequest-portal`**:

```powershell
npm ci
npm run dev
```

Откройте адрес, напечатанный Astro, обычно `http://localhost:4321/`. Открытие `.astro` или `dist/index.html` двойным щелчком не заменяет HTTP-сервер.

Версии зависимостей зафиксированы в `package.json` и `package-lock.json`. Для воспроизводимой установки используйте `npm ci` и сохраните lockfile в будущем репозитории. Обновляйте зависимости отдельно, с повторной проверкой и сборкой.

```powershell
npm run check
npm run build
npm run verify:links
npm run preview
```

`check` запускает Astro/TypeScript; `build` создаёт `dist/`; `verify:links` проверяет внутренние ссылки, ресурсы и якоря в результате сборки.

## Оформление и размер текста

Сохранена исходная пиксельная палитра: тёмно-синий фон тёмной темы, тёплый светлый фон светлой темы, цветные акценты и мягкие тени. Второстепенный текст в светлой теме сделан чёрным `#000` для лучшей читаемости; это также касается серых комментариев в коде. Тёмная тема сохраняет прежние светлые подписи.

Интерфейс оформлен в пиксельной тематике: квадратные панели, чёткие рамки и тени, кнопки с состоянием нажатия, авторская статичная SVG-сцена на главной. Оригинальные обложки курсов и учебные иллюстрации сохраняют своё изображение.

Заголовки и основные элементы управления используют локальный **CodeQuest Pixel** с латиницей и кириллицей; прописные формы нарисованы на сетке 5×7. Основной текст остаётся системным шрифтом: 20 px в интерфейсе, 22 px в методичках, код — 18 px на desktop и 17 px на телефоне. Таблицы и листинги прокручиваются внутри своей области. Тёмная и светлая темы используют один дизайн.

Шрифт находится в `src/assets/fonts/codequest-pixel.ttf` и включается в сборку локально. Исходная сетка и сборщик без зависимостей — `scripts/build-pixel-font.mjs`. Пересборка после правки сетки: `npm run font:build`; для обычной сборки эта команда не требуется. Внешних запросов к сервисам шрифтов нет.

В **Guild of Heroes доступны все 24 практические работы** с кодом, таблицами, иллюстрациями и последовательной навигацией. Обложка направления — исходный постер `start-poster-01-team_v3.webp`. Первая работа: `/practice/guild-of-heroes/lab-01/`.

В **Desktop Forge доступны все 12 работ Labs_Avalonia**: от первого окна и элементов ввода до привязок, MVVM, команд, JSON и собственного каталога. Обложка — скриншот каталога из работы №9; окно показывается целиком. Первая работа: `/practice/desktop-forge/lab-01/`.

В **Mobile Lab доступны все 14 практических работ GameBox**: крестики-нолики, змейка, морской бой и Android-релиз. Обложка — финальная иллюстрация с Битом из работы №14. Первая работа: `/practice/mobile-lab/lab-01/`. На странице курса можно скачать отдельную инструкцию по подготовке Android SDK.

В **Neon Arena доступны все 13 практических работ**: от первой сцены до Android. Для обложки использовано изображение арены с HUD из работы №9. На странице курса можно скачать исходные спрайты и звуки — архив из 48 файлов. Первая работа: `/practice/neon-arena/lab-01/`.

В **MediaHub доступны все 30 работ PixelPort** по дисциплине «Осуществление интеграции программных модулей». Пять модулей: вёрстка, TypeScript, API и БД, функции магазина, релиз. Обложка — исходный баннер `img/hero.png`. Первая работа: `/practice/mediahub/lab-01/`. Со страницы курса скачиваются обложки и интерфейс, скриншоты игр, данные и студенческие шаблоны.

Все пять направлений заполнены: доступны 93 реальные практические работы. Отдельные решения преподавателя не импортируются.

## Обновление «Гильдии героев»

Явный список студенческих работ находится в `content-map/guild-of-heroes.json`. Импортёр читает исходные файлы, создаёт копии для портала, переносит только используемые изображения, удаляет служебные комментарии с промптами и сохраняет содержимое всех листингов. Исходные папки не изменяются.

```powershell
npm run import:guild -- --dry-run
npm run import:guild -- --write
npm run verify:source
```

Повторный импорт проверяет манифест: вручную изменённые копии не перезаписываются молча. Для импорта исходные учебные папки должны быть рядом с порталом. Для обычной сборки и GitHub Pages они не нужны — все подключённые материалы уже находятся в самом проекте. Подробнее — [CONTENT_IMPORT.md](CONTENT_IMPORT.md).

## Обновление Neon Arena

## Проверки в браузере

После установки зависимостей и сборки запустите `npm run preview` в отдельном терминале. В другом:

```powershell
npm run test:browser
```

Используется установленный Chrome; скачивать Chromium для Playwright не требуется. Для Edge можно задать `$env:QA_BROWSER='msedge'`. Если предпросмотр выбрал другой порт, укажите `$env:QA_ORIGIN='http://localhost:4322'`.

Сценарий проверяет порядок карточек и фильтров, отсутствие ссылок на демо; проходит главную, пять курсов и первую работу Guild of Heroes на ширинах 1440/768/390/320, проверяет обе темы, переполнение, загрузку изображений, фильтр, копирование, оглавление и модальный просмотр; на desktop/mobile запускается axe. Скриншоты сохраняются в `qa/screenshots/`, машинный отчёт — в `qa/browser-report.json`.

`npm run test:guild` отдельно проверяет все 24 методички на ширинах 1440/390 в обеих темах, изображения, количество таблиц/листингов, соседние работы и обложку. Результат — `qa/guild-browser-report.json`, скриншоты — `qa/screenshots/guild-of-heroes/`. Фактический статус проверок см. в [QA_REPORT.md](QA_REPORT.md).

`npm run test:neon` проверяет тем же общим сценарием все 13 работ Neon Arena, обложку и ссылку на архив. Результат — `qa/neon-arena-browser-report.json`, скриншоты — `qa/screenshots/neon-arena/`. Общая реализация — `scripts/course-browser-qa.mjs`; новых копий сценария для каждого курса не требуется.

`npm run test:mobile` проверяет все 14 работ Mobile Lab, обложку и ссылку на инструкцию Android SDK. Отчёт — `qa/mobile-lab-browser-report.json`, скриншоты — `qa/screenshots/mobile-lab/`.

`npm run test:mediahub` проверяет все 30 работ PixelPort, обложку и архивы общим сценарием. Отчёт — `qa/mediahub-browser-report.json`, скриншоты — `qa/screenshots/mediahub/`.

`npm run test:desktop` проверяет все 12 работ Desktop Forge, обложку, навигацию и отображение методичек в двух темах и разрешениях. Отчёт — `qa/desktop-forge-browser-report.json`, скриншоты — `qa/screenshots/desktop-forge/`.

Если среда запрещает браузеру HTTP-подключение к localhost, можно проверить те же файлы сборки без сети: `$env:QA_LOCAL='1'; npm run test:guild`. Playwright передаст содержимое `dist/` браузеру через перехват запросов, не меняя HTML, CSS, JS и изображения. Для возвращения к обычной проверке удалите переменную: `Remove-Item Env:QA_LOCAL`.
