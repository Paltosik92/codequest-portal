# Настройка ноутбука к работе №07: Node.js

На компьютерах кабинета всё уже установлено. Этот гайд — для собственного ноутбука, сделай его **до занятия**: установка занимает 5–10 минут.

## Что нужно

| Программа | Версия | Зачем |
| --- | --- | --- |
| Node.js | 24.22.2 LTS | Запускает компилятор TypeScript |
| npm | 11.19.1 (идёт вместе с Node.js) | Ставит пакеты в проект |

TypeScript отдельно **не устанавливается**: он ставится в каждый проект командой `npm install` прямо на занятии.

## Проверь, может, уже стоит

В Git Bash:

```bash
node --version
npm --version
```

Если видишь `v24.22.2` и `11.19.1` (или более новую 24.x), всё готово.

## Установка

1. Открой страницу выпуска: <https://nodejs.org/en/blog/release/v24.22.2>.
2. Скачай установщик для Windows:
   - обычный компьютер — [x64 MSI](https://nodejs.org/dist/v24.22.2/node-v24.22.2-x64.msi);
   - ноутбук на ARM-процессоре — [ARM64 MSI](https://nodejs.org/dist/v24.22.2/node-v24.22.2-arm64.msi).
3. Запусти MSI, на всех шагах оставь значения по умолчанию. Галочку «Automatically install the necessary tools» (Chocolatey, Python, Visual Studio Build Tools) можно **не** ставить — для курса они не нужны.
4. **Закрой и снова открой VS Code и Git Bash** — иначе они не увидят новую программу.
5. Проверь версии командами выше.

## Если не работает

| Симптом | Что делать |
| --- | --- |
| `node: command not found` | Перезапусти VS Code и Git Bash. Не помогло — перезагрузи компьютер: установщик добавляет Node.js в PATH, и это иногда требует перезапуска |
| Версия старая, например `v18…` | Выполни `which node`: возможно, раньше в PATH стоит другая установка (через nvm или старый MSI). Удали старую через «Установка и удаление программ» |
| Ошибка про `npm.ps1` и Execution Policy | Ты в PowerShell. Переключи терминал VS Code на Git Bash |
| `npm install` долго висит или пишет `ETIMEDOUT` | Проверь интернет и VPN. Открой в браузере <https://registry.npmjs.org/> — должна загрузиться страница с текстом |

Терминал может предложить обновить npm («New major version of npm available»). На занятии **не обновляй**: версия npm зафиксирована для курса.
