## Цель работы

Познакомиться с созданием графических desktop-приложений на C# с помощью Avalonia.

В этой работе вы:

- создадите первый проект Avalonia;
- разберётесь в основных файлах проекта;
- познакомитесь с языком разметки AXAML;
- создадите простое окно;
- разместите в нём текст и кнопку;
- свяжете элементы интерфейса с C#-кодом;
- обработаете нажатие кнопки;
- измените содержимое интерфейса во время работы программы.

В этой практической работе **MVVM не используется**.

Мы начнём с более простого подхода:

```text

        ↕

```

Это позволит сначала разобраться, как вообще устроено графическое приложение.

## Краткая теория

### 1. Что такое Avalonia

**Avalonia** — это фреймворк для создания графических приложений на платформе .NET.

![Avalonia](/materials/desktop-forge/img/lab1/avalonia-platforms.webp)

С помощью него можно создавать desktop-приложения на C#, которые работают на разных операционных системах:

```text
Windows
Linux
macOS
```

Программа при этом состоит не только из C#-кода.

Интерфейс удобно описывать отдельно:

```text
AXAML
```

а поведение программы — на:

```text
C#
```

В нашей первой работе получится следующая связь:

```text
MainWindow.axaml
описание интерфейса

        ↓

MainWindow.axaml.cs
C#-код окна
```

---

### 2. AXAML — это не отдельная программа

Файл:

```text
MainWindow.axaml
```

описывает, **какие элементы должны находиться в окне и какими свойствами они обладают**.

Например:

```xml
<Button Content="Нажать" />
```

означает не просто «нарисовать кнопку».

`Button` — это настоящий класс Avalonia.

При создании интерфейса Avalonia создаёт объект этого класса.

То есть можно провести связь с уже изученным ООП:

```text
<Button />
    ↓
объект класса Button
```

А:

```xml
Content="Нажать"
```

задаёт значение одного из свойств этого объекта.

Поэтому AXAML тесно связан с классами и объектами C#.

![AXAML](/materials/desktop-forge/img/lab1/axaml-object.webp)

---

### 3. Свойства элементов

Например:

```xml
<TextBlock
    Text="Привет!"
    FontSize="24" />
```

Здесь создаётся элемент `TextBlock`.

Для него устанавливаются свойства:

```text
Text
FontSize
```

Примерно ту же идею можно представить обычным C#-кодом:

```csharp
TextBlock textBlock = new TextBlock();
textBlock.Text = "Привет!";
textBlock.FontSize = 24;
```

AXAML позволяет описывать такой интерфейс значительно компактнее.

---

### 4. Что такое событие

Пользователь может выполнять действия:

- нажать кнопку;
- выбрать элемент;
- изменить текст;
- закрыть окно.

Такие действия вызывают **события**.

Например, у кнопки есть событие:

```text
Click
```

Оно происходит, когда пользователь нажимает кнопку.

Мы можем указать метод, который должен выполниться при наступлении этого события.

Например:

```xml
<Button Click="ShowStatusButton_Click" />
```

А в C# создать метод:

```csharp
private void ShowStatusButton_Click(object? sender, RoutedEventArgs e)
{
    ...
}
```

Такой метод называется **обработчиком события**.

Схема работы:

```text
пользователь нажал кнопку
        ↓
событие Click
        ↓
ShowStatusButton_Click(...)
        ↓
выполняется C#-код
```

![Event](/materials/desktop-forge/img/lab1/click-event-flow.webp)

### `App.axaml`

Содержит общие настройки интерфейса приложения.

Например, здесь подключается стандартная тема Avalonia.

Настройки из `App.axaml` могут использоваться сразу во всём приложении.

В этой работе в файле нужно изменить одну строку.

Найдите в открывающем теге `Application` атрибут:

```xml
RequestedThemeVariant="Default"
```

Значение `Default` означает: «использовать тему операционной системы». Если в Windows включена тёмная тема, окно приложения тоже станет тёмным. В следующих работах мы будем задавать панелям светлый фон, и белый текст тёмной темы на нём станет нечитаемым.

Замените значение на:

```xml
RequestedThemeVariant="Light"
```

Если атрибута нет, добавьте его в тег `Application`.

Теперь приложение всегда использует светлую тему. **Делайте эту замену в каждой новой работе сразу после создания проекта.**

## Часть 4. Создание интерфейса

Откройте файл:

```text
MainWindow.axaml
```

Удалите его текущее содержимое и замените следующим:

```xml
<Window xmlns="https://github.com/avaloniaui"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        x:Class="AvaloniaLab01.MainWindow"
        Title="Карточка студента"
        Width="520"
        Height="420"
        MinWidth="420"
        MinHeight="340"
        WindowStartupLocation="CenterScreen">

    <StackPanel Margin="32"
                Spacing="12">

        <TextBlock Text="Карточка студента"
                   FontSize="28"
                   FontWeight="Bold" />

        <TextBlock Text="Первое приложение на Avalonia 12"
                   Opacity="0.7"
                   Margin="0,0,0,12" />

        <TextBlock Text="ФИО: Иван Иванов"
                   FontSize="18" />

        <TextBlock Text="Группа: ИСП-21"
                   FontSize="18" />

        <TextBlock Text="Специальность: Информационные системы и программирование"
                   FontSize="18"
                   TextWrapping="Wrap" />

        <TextBlock Text="Язык: C#"
                   FontSize="18" />

        <Button Content="Показать статус"
                HorizontalAlignment="Left"
                Margin="0,12,0,0" />

        <TextBlock Text="Статус: кнопка пока ничего не делает"
                   FontSize="16"
                   TextWrapping="Wrap" />

    </StackPanel>

</Window>
```

## Разбираем новый AXAML

### `Window`

Корневой элемент:

```xml
<Window>
```

представляет главное окно приложения.

У него установлены свойства:

```xml
Title="Карточка студента"
Width="520"
Height="420"
```

`Title` задаёт заголовок окна.

`Width` и `Height` задают начальную ширину и высоту.

---

### Что означает `x:Class`

В начале файла находится:

```xml
x:Class="AvaloniaLab01.MainWindow"
```

Эта строка связывает AXAML с C#-классом:

```csharp
AvaloniaLab01.MainWindow
```

То есть:

```text
MainWindow.axaml
        +
MainWindow.axaml.cs
        ↓
одно окно MainWindow
```

---

### `StackPanel`

Внутри окна находится:

```xml
<StackPanel>
```

`StackPanel` — это контейнер.

Контейнер хранит другие элементы интерфейса.

По умолчанию `StackPanel` располагает свои дочерние элементы друг под другом:

```text
элемент 1
элемент 2
элемент 3
элемент 4
```

В следующих работах мы познакомимся и с другими способами построения интерфейса.

---

### `Margin`

Запись:

```xml
Margin="32"
```

создаёт внешний отступ вокруг содержимого.

То есть элементы не будут прижаты к границам окна.

---

### `Spacing`

Свойство:

```xml
Spacing="12"
```

создаёт расстояние между элементами внутри `StackPanel`.

Без него элементы располагались бы слишком близко друг к другу.

---

### `TextBlock`

`TextBlock` используется для отображения текста:

```xml
<TextBlock Text="Язык: C#" />
```

Главное свойство:

```text
Text
```

содержит отображаемую строку.

---

### `Button`

Кнопка создаётся так:

```xml
<Button Content="Показать статус" />
```

У кнопки используется свойство:

```text
Content
```

Оно задаёт содержимое кнопки.

Пока кнопка присутствует на экране, но **никакого C#-действия с ней не связано**.

Это мы исправим дальше.

## Часть 7. Связываем кнопку с C#

Сейчас у нас есть проблема:

```text
кнопка есть
```

### Шаг 1. Добавляем имя текстовому элементу

Откройте:

```text
MainWindow.axaml
```

Найдите последний `TextBlock`:

```xml
<TextBlock Text="Статус: кнопка пока ничего не делает"
```

```xml
<TextBlock x:Name="StatusText"
```

```xml
x:Name="StatusText"
```

### Что такое `x:Name`

Обычно Avalonia сама создаёт элементы интерфейса, и нам не требуется обращаться к каждому из них из C#.

Но иногда необходимо получить конкретный элемент.

Например, мы хотим изменить:

```text
Text
```

у нашего `TextBlock`.

Для этого элементу даётся имя:

```xml
x:Name="StatusText"
```

После этого из C# мы сможем обратиться к нему:

```csharp
StatusText.Text
```

Связь выглядит так:

```text
AXAML

x:Name="StatusText"

        ↓

C#

StatusText.Text = "...";
```

![x:Name](/materials/desktop-forge/img/lab1/xname-connection.webp)

---

### Шаг 2. Добавляем событие кнопке

Найдите кнопку:

```xml
<Button Content="Показать статус"
        HorizontalAlignment="Left"
        Margin="0,12,0,0" />
```

Замените её:

```xml
<Button Content="Показать статус"
        Click="ShowStatusButton_Click"
        HorizontalAlignment="Left"
        Margin="0,12,0,0" />
```

Мы добавили:

```xml
Click="ShowStatusButton_Click"
```

Это означает:

> когда произойдёт событие `Click`, вызови метод `ShowStatusButton_Click`.

Но самого метода пока ещё нет.

## Часть 8. Первый обработчик события

Откройте:

```text
MainWindow.axaml.cs
```

Сейчас файл выглядит примерно так:

```csharp
using Avalonia.Controls;

namespace AvaloniaLab01;

public partial class MainWindow : Window
{
    public MainWindow()
    {
        InitializeComponent();
    }
}
```

---

### Что здесь происходит

#### `MainWindow : Window`

Класс:

```csharp
MainWindow
```

наследуется от:

```csharp
Window
```

То есть главное окно нашего приложения — это класс.

Здесь напрямую используется уже знакомое вам **наследование**.

```text
Window
  ↑
MainWindow
```

---

### Почему класс `partial`

Обратите внимание:

```csharp
public partial class MainWindow
```

Ключевое слово:

```csharp
partial
```

означает, что описание одного класса может быть разделено на несколько частей.

Одна часть класса находится в нашем C#-файле.

Другую часть Avalonia создаёт автоматически на основе AXAML.

Упрощённо:

```text
MainWindow.axaml
      ↓
сгенерированная часть класса
      +
MainWindow.axaml.cs
      ↓
MainWindow
```

Нам не нужно вручную писать сгенерированную часть.

---

### Что делает `InitializeComponent()`

В конструкторе находится:

```csharp
InitializeComponent();
```

Этот вызов загружает интерфейс, описанный в AXAML.

Поэтому удалять его нельзя.

---

### Шаг 1. Подключаем пространство имён событий

В начале файла после:

```csharp
using Avalonia.Controls;
```

добавьте:

```csharp
using Avalonia.Interactivity;
```

Получится:

```csharp
using Avalonia.Controls;
using Avalonia.Interactivity;
```

---

### Шаг 2. Добавляем обработчик

После конструктора:

```csharp
public MainWindow()
{
    InitializeComponent();
}
```

добавьте:

```csharp
private void ShowStatusButton_Click(object? sender, RoutedEventArgs e)
{
    StatusText.Text = "Статус: приложение работает!";
}
```

Итоговый файл:

```csharp
using Avalonia.Controls;
using Avalonia.Interactivity;

namespace AvaloniaLab01;

public partial class MainWindow : Window
{
    public MainWindow()
    {
        InitializeComponent();
    }

    private void ShowStatusButton_Click(object? sender, RoutedEventArgs e)
    {
        StatusText.Text = "Статус: приложение работает!";
    }
}
```

## Разбираем обработчик

Метод:

```csharp
private void ShowStatusButton_Click(object? sender, RoutedEventArgs e)
```

является обработчиком события.

Пока нам важны три части.

---

### Имя метода

```csharp
ShowStatusButton_Click
```

Именно это имя мы указали в AXAML:

```xml
Click="ShowStatusButton_Click"
```

Имена должны совпадать.

---

### `sender`

```csharp
object? sender
```

`sender` содержит объект, который вызвал событие.

В нашем случае событие вызвала кнопка.

Позже это может быть полезно, но сейчас параметр использовать не требуется.

---

### `RoutedEventArgs e`

```csharp
RoutedEventArgs e
```

Этот параметр содержит информацию о произошедшем событии.

В этой работе мы его также не используем.

---

### Главное действие

```csharp
StatusText.Text = "Статус: приложение работает!";
```

Здесь происходит обычная работа со свойством объекта.

Мы обращаемся к элементу:

```text
StatusText
```

и изменяем его свойство:

```text
Text
```

То есть идея практически такая же, как у обычного объекта C#:

```csharp
объект.Свойство = новоеЗначение;
```
