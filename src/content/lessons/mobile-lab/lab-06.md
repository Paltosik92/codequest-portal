**Дисциплина:** «Разработка мобильных приложений».
**Начало:** ваш GameBox после полностью выполненной ПР5.

Змейка уже движется по полю, слушается стрелок и останавливается при выходе или сворачивании. Бит наблюдает за тремя сегментами: «Движение есть. Теперь нужна цель».

Сегодня на поле появится еда. Змейка сможет добраться до неё, сохранить хвост, вырасти на один сегмент и получить 10 очков. Следующая еда будет выбираться только из свободных клеток — даже если почти всё поле уже занято.

Продолжаем ту же модель и тот же экран. Таймер, направления и жизненный цикл ПР5 не проектируем заново: меняется результат одного уже знакомого шага.

![Бит показывает единственную еду перед движущейся змейкой, у которой теперь появляется цель маршрута](/materials/mobile-lab/img/lab6/comic-01-snake-needs-goal.webp)

_Название работы говорит о яблоках; в обязательной версии еда изображается простым стандартным оформлением клетки без новых ресурсов._

## Результат занятия

После обязательной части змейка:

- продолжает двигаться по полю 16×16 с управлением ПР5;
- хранит одну координату еды в модели;
- съедает еду только при настоящем шаге головы в её клетку;
- при обычном шаге сохраняет длину;
- при съедании вырастает ровно на один сегмент;
- получает ровно +10 очков за одну еду;
- выбирает новую еду из списка свободных клеток после изменения тела;
- не вызывает `Random.nextInt(0)` при отсутствии свободного места;
- успешно завершает движение при заполнении всего поля;
- сбрасывает очки, тело, направления, фазу и еду через «В начало».

На экране появятся еда и текущие очки. Существующие запуск, продолжение после фоновой паузы, стрелки и безопасная остановка у края сохраняются.

**Полный проигрыш ещё не добавляем.** Столкновение с телом не вызывает Game Over, край остаётся диагностической остановкой ПР5. Рекорда, сохранения очков, ускорения, свайпов, бонусов и новой кнопки паузы здесь нет.

![После первого съедания экран показывает 10 очков, четыре сегмента и одну новую еду в свободной клетке](/materials/mobile-lab/img/lab6/ui-01-food-and-score.webp)

_Макет соответствует промежуточной проверке с фиксированной первой едой. В итоговом коде положение еды случайное, а правила роста те же._

## Как работать с методичкой

Откройте **конец ПР5**, где вместо временной кнопки «Один шаг» уже работают «Старт» и один `Timer.periodic`. Два быстрых запроса не должны обходить защиту направления.

Пути `lib/...` и `test/...` относятся к корню вашего Flutter-проекта. `img/lab6/...` — только иллюстрации методички: они не добавляются в `assets` приложения.

Готовую инфраструктуру копируйте. Самостоятельно дополняются четыре коротких места: сравнение головы с едой, выбор удаления хвоста, +10 и фильтр свободных клеток. В тесте добавите одну проверку по образцу.

Маршрут состоит из двух рабочих состояний: сначала фиксированная еда рядом и рост, затем случайное размещение и граничные тесты. Промежуточный способ размещения тоже выбирает свободное место; ошибку специально создадим только в отдельном эксперименте.

## 2. Подготавливаем модель, еду и очки

### 2.1. Что теперь хранит модель

Добавляем:

- `GridPosition? food` — клетка еды; `null` означает, что еды нет при заполненном поле;
- `int score` — текущие очки, начиная с 0;
- `SnakePhase.filled` — успешное заполнение поля, без проигрыша.

`filled` нужен для остановки цикла и понятного статуса. Это не система Game Over ПР7. В рабочей неполной партии еда одна, при успешном заполнении её больше негде размещать.

### 2.2. Почти готовый файл модели

Замените **весь `lib/games/snake/snake_game.dart`** следующим кодом. Все защиты направления ПР5 уже сохранены. Три помеченных учебных места заполните на этапе 3 **до первого запуска движения**.

```dart
import '../../core/grid_position.dart';

enum Direction { up, down, left, right }

enum SnakePhase { ready, running, paused, edgeStopped, filled }

class SnakeGame {
  SnakeGame() {
    reset();
  }

  static const int size = 16;
  static const List<GridPosition> _initialSnake = [
    GridPosition(8, 8),
    GridPosition(8, 7),
    GridPosition(8, 6),
  ];

  final List<GridPosition> snake = List<GridPosition>.of(_initialSnake);
  Direction direction = Direction.right;
  Direction requestedDirection = Direction.right;
  SnakePhase phase = SnakePhase.ready;
  GridPosition? food;
  int score = 0;

  bool start() {
    if (phase == SnakePhase.running || phase == SnakePhase.edgeStopped ||
        phase == SnakePhase.filled) {
      return false;
    }
    phase = SnakePhase.running;
    return true;
  }

  void pause() {
    if (phase != SnakePhase.running) return;
    phase = SnakePhase.paused;
    requestedDirection = direction;
  }

  bool requestDirection(Direction next) {
    if (phase != SnakePhase.running || next == direction) return false;
    if (_isOpposite(direction, next)) return false;
    if (requestedDirection != direction) return false;
    requestedDirection = next;
    return true;
  }

  bool _isOpposite(Direction first, Direction second) {
    return (first == Direction.up && second == Direction.down) ||
        (first == Direction.down && second == Direction.up) ||
        (first == Direction.left && second == Direction.right) ||
        (first == Direction.right && second == Direction.left);
  }

  GridPosition _nextHead(Direction next) {
    final head = snake.first;
    switch (next) {
      case Direction.up:
        return head.shifted(-1, 0);
      case Direction.down:
        return head.shifted(1, 0);
      case Direction.left:
        return head.shifted(0, -1);
      case Direction.right:
        return head.shifted(0, 1);
    }
  }

  bool _inside(GridPosition position) {
    return position.row >= 0 && position.row < size &&
        position.col >= 0 && position.col < size;
  }

  bool step() {
    if (phase != SnakePhase.running) return false;
    final next = requestedDirection;
    final newHead = _nextHead(next);
    if (!_inside(newHead)) {
      phase = SnakePhase.edgeStopped;
      requestedDirection = direction;
      return false;
    }

    final ateFood = false; // Учебное место 1: условие съедания.
    direction = next;
    snake.insert(0, newHead);
    snake.removeLast(); // Учебное место 2: выбор удаления хвоста.
    if (ateFood) {
      // Учебное место 3: начисление очков.
      _placeFood();
    }
    requestedDirection = direction;
    return true;
  }

  void _placeFood() {
    // Промежуточная версия: первая свободная клетка без случайности.
    for (var row = 0; row < size; row++) {
      for (var col = 0; col < size; col++) {
        final position = GridPosition(row, col);
        if (snake.contains(position)) continue;
        food = position;
        return;
      }
    }
    food = null;
    phase = SnakePhase.filled;
  }

  void reset() {
    snake
      ..clear()
      ..addAll(_initialSnake);
    direction = Direction.right;
    requestedDirection = Direction.right;
    phase = SnakePhase.ready;
    score = 0;
    food = const GridPosition(8, 9);
  }
}
```

Первая еда специально стоит рядом, чтобы первый рост можно было воспроизвести. После съедания временный `_placeFood` выбирает первую свободную клетку при обходе по строкам. Он уже безопасен, но пока предсказуем. На этапе 4 заменим его случайным выбором и подключим его также к `reset`.

Новая модель по-прежнему не импортирует Flutter, не создаёт таймер и не обращается к хранилищу. Её `step` делает ровно один переход.

### 2.3. Статус и остановка успешного заполнения

      SnakePhase.filled => 'Поле заполнено — все клетки заняты!',

В этом же файле замените **два метода `_startMovement` и `_onTick` целиком** одним готовым блоком:

```dart
  void _startMovement() {
    if (_leaving || _game.phase == SnakePhase.running ||
        _game.phase == SnakePhase.edgeStopped ||
        _game.phase == SnakePhase.filled) {
      return;
    }
    _cancelTimer();
    if (!_game.start()) return;
    _timer = Timer.periodic(const Duration(milliseconds: 400), _onTick);
    setState(() {});
  }

  void _onTick(Timer timer) {
    if (!mounted || _leaving || timer != _timer ||
        _game.phase != SnakePhase.running) {
      timer.cancel();
      return;
    }
    _game.step();
    if (_game.phase != SnakePhase.running) _cancelTimer();
    setState(() {});
  }
```

Почему изменился конец `_onTick`? Последний рост действительно перемещает тело и возвращает `true`, но может завершить поле. Таймер нужно отменить сразу по конечной **фазе**, а не ждать следующего неуспешного шага.

Найдите **весь `FilledButton` запуска из конца ПР5** и замените:

```dart
                  FilledButton(
                    onPressed: _game.phase == SnakePhase.running ||
                            _game.phase == SnakePhase.edgeStopped ||
                            _game.phase == SnakePhase.filled
                        ? null : _startMovement,
                    child: Text(_game.phase == SnakePhase.paused
                        ? 'Продолжить' : 'Старт'),
                  ),
```

Все методы отмены, паузы, выхода, reset и `dispose` остаются прежними. Новая кнопка паузы не нужна.

### 2.4. Готовая отрисовка еды

Замените **только метод `_buildCell` целиком**:

```dart
  Widget _buildCell(int index) {
    final colors = Theme.of(context).colorScheme;
    final position = GridPosition(
      index ~/ SnakeGame.size,
      index % SnakeGame.size,
    );
    final isHead = position == _game.snake.first;
    final isBody = _game.snake.contains(position);
    final isFood = position == _game.food;
    Widget? marker;
    if (isHead) {
      marker = FractionallySizedBox(
        widthFactor: 0.4,
        heightFactor: 0.4,
        child: DecoratedBox(decoration: BoxDecoration(
          color: colors.onPrimary,
          shape: BoxShape.circle,
        )),
      );
    } else if (isFood) {
      marker = FractionallySizedBox(
        widthFactor: 0.7,
        heightFactor: 0.7,
        child: DecoratedBox(decoration: BoxDecoration(
          color: colors.errorContainer,
          shape: BoxShape.circle,
          border: Border.all(color: colors.error, width: 2),
        )),
      );
    }

    return DecoratedBox(
      decoration: BoxDecoration(
        color: isHead
            ? colors.primary
            : isBody ? colors.primaryContainer : colors.surfaceContainerHighest,
        border: Border.all(color: colors.outlineVariant, width: 0.5),
        borderRadius: BorderRadius.circular(2),
      ),
      child: marker == null ? null : Center(child: marker),
    );
  }
```

`isFood` только сравнивает координаты. Здесь нет генерации, изменения score или удаления еды. Круг с обводкой отличается от маленькой точки головы размером и оформлением, а не только цветом.

## 3. Дополняем рост и начисление очков

### 3.1. Два варианта одного тика

Возьмём понятную позицию:

```text
snake = [(5,5), (5,4), (5,3)]
direction = right
score = 0
```

Будущая голова — `(5, 6)`.

| Случай              | Что делаем с хвостом      | Результат                                      |
| ------------------- | ------------------------- | ---------------------------------------------- |
| Еда в другой клетке | Удаляем последний сегмент | `(5,6), (5,5), (5,4)`, длина 3, очки 0         |
| `food == (5,6)`     | Оставляем хвост           | `(5,6), (5,5), (5,4), (5,3)`, длина 4, очки 10 |

Голова добавляется в обоих случаях. Различается именно решение об удалении старого хвоста.

![В обычном шаге хвост удаляется и длина сохраняется, а при входе в еду хвост остаётся и длина увеличивается на один](/materials/mobile-lab/img/lab6/schema-01-growth-step.webp)

_При росте не добавляем отдельный сегмент ещё раз: он уже появился как новая голова._

### 3.2. Самостоятельная часть: сравнение с food

В **`snake_game.dart`**, внутри `step`, замените всю строку `final ateFood = false; // Учебное место 1: условие съедания.` сравнением будущей головы и текущей еды.

**Подсказка:** обе координаты представлены `GridPosition`; нужное равенство уже создано в ПР5. Сравниваем `newHead`, а не старую `snake.first`.

Готовая строка:

```dart
    final ateFood = newHead == food;
```

Она стоит после проверки границы и **до** изменения списка/еды. Так запоминаем причину этого конкретного шага, пока `food` ещё указывает на прежнюю еду.

### 3.3. Самостоятельная часть: оставить хвост при росте

Замените всю строку `snake.removeLast(); // Учебное место 2: выбор удаления хвоста.` условием удаления только при обычном шаге.

**Подсказка:** `ateFood` уже сообщает, съели ли еду. Отрицание — `!`.

Готовый блок:

```dart
    if (!ateFood) snake.removeLast();
```

Не удаляйте хвост, чтобы затем добавлять его обратно: у нас уже есть простая развилка до удаления.

### 3.4. Самостоятельная часть: +10 один раз

Внутри `if (ateFood)` замените комментарий `// Учебное место 3: начисление очков.` увеличением score на 10.

Готовая строка:

```dart
      score += 10;
```

Следующий `_placeFood()` вызывается после добавления головы и решения о хвосте. Новая еда выбирается по **новому** телу, иначе только что появившаяся голова могла бы остаться среди «свободных» клеток.

2. Сравнивается будущая голова с прежней едой.
3. При еде хвост остаётся, длина увеличивается на 1, score на 10.
4. Без еды длина и очки не растут.
5. Reset возвращает 0 и корректную еду; первый checkpoint сохранён.

**Контрольная точка:** рост работает. Теперь сделаем расположение следующей цели случайным, сохранив допустимость.

## 4. Выбираем еду только из свободных клеток

### 4.1. Сначала допустимость, затем Random

Не угадываем координату снова и снова. На почти заполненном поле такое угадывание будет всё чаще попадать в тело; при отсутствии свободных мест оно вообще не даст результата.

Используем конечный перебор:

```text
256 координат поля
→ исключили занятые змейкой
→ список freeCells
→ если список пуст, успешно закончили движение
→ иначе Random выбрал позицию в этом списке
→ food получила соответствующую координату
```

Один проход по 256 клеткам подходит нашей учебной задаче. Не нужен новый оптимизированный контейнер занятости или универсальный генератор игрового мира.

![После исключения тела Random выбирает координату из freeCells, а пустой список завершает поле без вызова случайного индекса](/materials/mobile-lab/img/lab6/schema-02-free-cells.webp)

_Если свободна одна клетка, случайность уже ничего не меняет: именно она станет едой._

### 4.2. Готовая передача Random

В **`snake_game.dart`** перед существующим импортом GridPosition добавьте:

```dart
import 'dart:math';
```

В начале `SnakeGame` замените **весь текущий конструктор** `SnakeGame() { reset(); }` блоком конструктора и одного поля:

```dart
  SnakeGame({Random? random}) : _random = random ?? Random() {
    reset();
  }

  final Random _random;
```

Обычный `SnakeGame()` в экране продолжает работать. Параметр нужен тесту, который может передать `Random(17)` или готовый предсказуемый источник. Это не новая система управления зависимостями, а один необязательный аргумент знакомого класса.

### 4.3. Почти готовое случайное размещение

Замените **метод `_placeFood` целиком** следующим вариантом:

```dart
  void _placeFood() {
    final freeCells = <GridPosition>[];
    for (var row = 0; row < size; row++) {
      for (var col = 0; col < size; col++) {
        final position = GridPosition(row, col);
        if (snake.contains(position)) {
          // Учебное место 4: пропустите занятую клетку.
        }
        freeCells.add(position);
      }
    }

    if (freeCells.isEmpty) {
      food = null;
      phase = SnakePhase.filled;
      return;
    }
    food = freeCells[_random.nextInt(freeCells.length)];
  }
```

До запуска заполните фильтр. Словами: если змейка уже содержит эту координату, перейти к следующему столбцу; добавлять в список только оставшиеся координаты.

**Самостоятельно:** замените комментарий `// Учебное место 4: пропустите занятую клетку.` одним оператором `continue;`.

Итоговый фильтр для восстановления:

```dart
        if (snake.contains(position)) {
          continue;
        }
        freeCells.add(position);
```

`continue` относится к внутреннему циклу по столбцам. Строка `freeCells.add` для занятой клетки не выполняется. Оператор `break` здесь не подходит: он пропустил бы ещё и оставшиеся столбцы текущей строки.

### 4.4. Подключаем размещение к новой игре

В **конце `reset`** замените только строку:

```dart
    food = const GridPosition(8, 9);
```

на:

```dart
    _placeFood();
```

Сброс сначала восстанавливает тело, направления, `ready` и score 0, и лишь затем выбирает еду по этому телу. При каждом новом запуске через «В начало» она может оказаться в другой свободной клетке.

Теперь одинаковый метод используется после съедания и при reset. Старая фиксированная строка нужна только для восстановления и первого учебного checkpoint; в итоговом `reset` её не оставляем.

### 4.5. Сверяем порядок событий

```text
вычислить будущую голову
→ проверить границу ПР5
→ сравнить будущую голову со старой food
→ добавить голову
→ если еды нет, удалить хвост
→ если еда есть, +10 и выбрать новую food по новому телу
→ завершить один step
```

![Очки увеличиваются один раз в step после входа головы в еду, а build лишь читает текущие очки и рисует поле](/materials/mobile-lab/img/lab6/schema-03-score-event.webp)

_Повторное рисование не является новым съеданием. В `build` нет ни `score += 10`, ни `_placeFood`._

Сохраните файлы, выполните `flutter analyze` и перезапустите приложение. Несколько раз нажмите «В начало»: еда всегда вне трёх стартовых сегментов. Не требуйте, чтобы каждый новый выбор обязательно отличался от предыдущего: случайность может повторить допустимую клетку.

## Проверяем

1. Перебираются все 16×16 координат с индексами 0…15.
2. Занятая клетка не попадает в `freeCells`.
3. Проверка пустого списка стоит до `nextInt`.
4. После еды и при reset используется один `_placeFood`.
5. В UI нет собственной позиции еды или генератора.

**Контрольная точка:** размещение стало случайным. Теперь проверим редкие состояния готовыми тестами.

## 5. Создаём первые тесты змейки

### 5.1. Почему не заполняем поле вручную

Собрать змейку из 254 сегментов обычной игрой долго. Тест может подготовить корректное тело, еду перед головой и выполнить один `step` без таймера и окна приложения.

Готовые данные ниже образуют непрерывный путь по строкам: первая строка слева направо, следующая справа налево. Список перевёрнут так, чтобы голова находилась в конце пройденного пути, а хвост — в начале.

Проверяем две последние свободные клетки:

| До шага                             | Голова                    | Еда перед головой | Что останется после роста                        |
| ----------------------------------- | ------------------------- | ----------------- | ------------------------------------------------ |
| 254 сегмента, два свободных места   | (15, 2), направление LEFT | (15, 1)           | Единственная свободная (15, 0) станет новой едой |
| 255 сегментов, одно свободное место | (15, 1), направление LEFT | (15, 0)           | Свободных нет, food=null, фаза filled            |

Тело не содержит повторов, а очки соответствуют длине: `(длина − 3) × 10`. Эти большие позиции существуют **только в тестовом файле**, в пользовательское меню они не добавляются.

### 5.2. Готовый файл тестов

Создайте **`test/snake_game_test.dart`** целиком. В двух импортах замените `gamebox_ivanov` на своё значение `name` из `pubspec.yaml`; само имя пакета не переименовывайте.

```dart
import 'dart:math';

import 'package:flutter_test/flutter_test.dart';
import 'package:gamebox_ivanov/core/grid_position.dart';
import 'package:gamebox_ivanov/games/snake/snake_game.dart';

// Готовый источник для граничных случаев: выбирает первый допустимый элемент.
class FirstRandom implements Random {
  @override
  int nextInt(int max) {
    if (max <= 0) throw ArgumentError.value(max, 'max');
    return 0;
  }

  @override
  bool nextBool() => false;

  @override
  double nextDouble() => 0.0;
}

SnakeGame foodAhead() {
  final game = SnakeGame(random: FirstRandom());
  game.snake
    ..clear()
    ..addAll(const [
      GridPosition(5, 5), GridPosition(5, 4), GridPosition(5, 3),
    ]);
  game.food = const GridPosition(5, 6);
  return game;
}

SnakeGame almostFull(int emptyCells) {
  assert(emptyCells == 1 || emptyCells == 2);
  final path = <GridPosition>[
    for (var row = 0; row < SnakeGame.size; row++)
      for (var offset = 0; offset < SnakeGame.size; offset++)
        GridPosition(row, row.isEven ? offset : SnakeGame.size - 1 - offset),
  ];
  final count = path.length - emptyCells;
  final game = SnakeGame(random: FirstRandom());
  game.snake
    ..clear()
    ..addAll(path.take(count).toList().reversed);
  game.direction = Direction.left;
  game.requestedDirection = Direction.left;
  game.food = path[count];
  game.score = (count - 3) * 10;
  return game;
}

void main() {
  test('Обычный тик сохраняет длину, очки и еду', () {
    final game = SnakeGame(random: FirstRandom());
    game.food = const GridPosition(15, 15);
    game.start();
    expect(game.step(), isTrue);
    expect(game.snake, const [
      GridPosition(8, 9), GridPosition(8, 8), GridPosition(8, 7),
    ]);
    expect(game.score, 0);
    expect(game.food, const GridPosition(15, 15));
  });

  test('Еда рядом: длина +1 и +10 очков', () {
    final game = foodAhead()..start();
    expect(game.step(), isTrue);
    expect(game.snake, const [
      GridPosition(5, 6), GridPosition(5, 5),
      GridPosition(5, 4), GridPosition(5, 3),
    ]);
    expect(game.snake.length, 4);
    expect(game.score, 10);
    expect(game.food, isNotNull);
    expect(game.snake.contains(game.food), isFalse);
  });

  test('Следующий обычный тик не даёт повторного роста и очков', () {
    final game = foodAhead()..start();
    game.step();
    game.food = const GridPosition(15, 15);
    expect(game.step(), isTrue);
    expect(game.snake.length, 4);
    expect(game.score, 10);
  });

  test('После роста остаётся одна свободная клетка', () {
    final game = almostFull(2)..start();
    expect(game.snake.toSet().length, 254);
    expect(game.step(), isTrue);
    expect(game.snake.length, 255);
    expect(game.snake.first, const GridPosition(15, 1));
    expect(game.food, const GridPosition(15, 0));
    expect(game.snake.contains(game.food), isFalse);
    expect(game.score, 2520);
    expect(game.phase, SnakePhase.running);
  });

  test('Последняя еда успешно заполняет поле без nextInt(0)', () {
    final game = almostFull(1)..start();
    expect(game.step(), isTrue);
    expect(game.snake.length, 256);
    expect(game.snake.toSet().length, 256);
    expect(game.score, 2530);
    expect(game.food, isNull);
    expect(game.phase, SnakePhase.filled);
    final before = List<GridPosition>.of(game.snake);
    expect(game.start(), isFalse);
    expect(game.step(), isFalse);
    expect(game.snake, before);
    expect(game.score, 2530);
  });

  test('Reset очищает завершение и возвращает допустимую еду', () {
    final game = almostFull(1)..start();
    game.step();
    game.reset();
    expect(game.snake.length, 3);
    expect(game.snake.first, const GridPosition(8, 8));
    expect(game.phase, SnakePhase.ready);
    expect(game.direction, Direction.right);
    expect(game.requestedDirection, Direction.right);
    expect(game.food, isNotNull);
    expect(game.snake.contains(game.food), isFalse);
    // Добавьте проверку score по разделу 5.3.
  });

  test('Еда допустима при разных seed и после reset', () {
    for (var seed = 0; seed < 20; seed++) {
      final game = SnakeGame(random: Random(seed));
      for (var attempt = 0; attempt < 3; attempt++) {
        final food = game.food!;
        expect(food.row, inInclusiveRange(0, 15));
        expect(food.col, inInclusiveRange(0, 15));
        expect(game.snake.contains(food), isFalse);
        game.reset();
      }
    }
  });

  test('Один seed даёт воспроизводимую последовательность в этой среде', () {
    final first = SnakeGame(random: Random(17));
    final second = SnakeGame(random: Random(17));
    for (var attempt = 0; attempt < 5; attempt++) {
      expect(first.food, second.food);
      first.reset();
      second.reset();
    }
  });

  test('Защита направления и диагностический край ПР5 сохранены', () {
    final game = SnakeGame(random: FirstRandom());
    game.food = const GridPosition(0, 0);
    game.start();
    expect(game.requestDirection(Direction.left), isFalse);
    expect(game.requestDirection(Direction.up), isTrue);
    expect(game.requestDirection(Direction.down), isFalse);
    expect(game.direction, Direction.right);
    expect(game.step(), isTrue);
    expect(game.snake.first, const GridPosition(7, 8));
    for (var step = 0; step < 7; step++) {
      expect(game.step(), isTrue);
    }
    expect(game.step(), isFalse);
    expect(game.phase, SnakePhase.edgeStopped);
    expect(game.snake.first, const GridPosition(0, 8));
    expect(game.score, 0);
  });
}
```

`FirstRandom` и оба помощника — готовая тестовая инфраструктура. Не переносите их в `lib` и не создавайте в приложении кнопку загрузки больших змей.

`FirstRandom.nextInt` возвращает 0 только при положительном размере. Если модель ошибочно попросит `nextInt(0)`, тест получит исключение. Это позволяет проверить защиту пустого списка без настоящей случайности.

### 5.3. Самостоятельная проверка score после reset

В тесте `Reset очищает завершение и возвращает допустимую еду` замените комментарий проверкой, что score стал 0. По образцу соседних `expect` нужна одна строка:

```dart

```

Здесь перед reset было 2530 очков, поэтому проверка действительно заметит забытый сброс. Проверка reset от только что созданной игры с нулём была бы слабее.

## 6. Проверяем завершение, таймер и новую игру

### 6.1. Поле заполнено — это успешная остановка

В последнем граничном тесте до шага заняты 255 разных клеток. Голова входит в последнюю свободную еду:

```text
255 сегментов → 256
2520 очков → 2530
freeCells пуст
food = null
phase = filled
```

Не проверяем заполнение только по `snake.length == 256`. В ПР6 ещё нет запрета столкновения с телом: если сегменты накладывались, длина списка сама по себе не доказывает занятость всех клеток. Источник решения — отсутствие свободных координат после фильтрации.

Обычный `step` возвращает `true`, потому что последний ход принят. Сразу после него экран проверяет фазу и отменяет таймер. Повторные шаги в `filled` возвращают `false` и не дают новых очков.

На экране при таком результате должны остаться поле, итоговые текущие очки и статус «Поле заполнено — все клетки заняты!». «Старт» и стрелки отключены; «В начало» и возврат доступны. Нового Game Over overlay и сохранения результата нет.

Не пытайтесь получить это состояние долгой игрой в оставшиеся минуты: модельный тест уже воспроизводит последний шаг. Смысл экранной обвязки проследите по `_onTick` и общей таблице:

| После step                    | Вернулся bool | Действие экрана                            |
| ----------------------------- | ------------- | ------------------------------------------ |
| Обычное движение              | true          | Показать новое положение, оставить таймер  |
| Еда, свободные места остались | true          | Показать рост и +10, оставить таймер       |
| Еда заполнила поле            | true          | Показать filled и отменить таймер          |
| Попытка выйти за край         | false         | Показать диагностику ПР5 и отменить таймер |

### 6.2. Reset — не только нулевые очки

После съедания нажмите «В начало» и проверьте:

| Данные               | После сброса                            |
| -------------------- | --------------------------------------- |
| `snake`              | (8,8), (8,7), (8,6)                     |
| `direction`          | right                                   |
| `requestedDirection` | right                                   |
| `phase`              | ready                                   |
| `score`              | 0                                       |
| `food`               | Одна случайная свободная клетка         |
| Таймер экрана        | Отменён, движения нет до явного запуска |

Несколько раз повторите «Старт → еда или несколько шагов → В начало». Сброс не должен оставлять прежнюю длину, старые очки или таймер. Новая еда иногда может совпасть с прежней допустимой координатой — это не ошибка.

Фиксированные большие тела тестов reset тоже очищает. Поэтому тест начинается с завершённого поля, а не с уже пустого счёта.

### 6.3. Проверка события, а не кадра

После одного съедания остановите движение фоновой паузой. Посмотрите на очки, измените размер окна или дождитесь нескольких перерисовок. Без нового шага score остаётся прежним.

Если число растёт на месте, найдите запись `score += 10`: она должна быть только в ветке `if (ateFood)` модели. Не пытайтесь исправить это задержкой обновления надписи в UI.

Возврат на полку или открытие About также не начисляют очки. При повторном открытии экрана змейки создаётся новая попытка с 0: незаконченная игра между маршрутами и запусками не восстанавливается.

## Проверяем

1. `filled` означает успешное заполнение, а не проигрыш.
2. Таймер отменяется по конечной фазе сразу после шага.
3. Последний съеденный объект не оставляет food на голове: food становится null.
4. Reset возвращает все исходные данные и одну допустимую еду.
5. Перерисовки и другие экраны не меняют текущие очки.

**Контрольная точка:** полный цикл «движение → еда → рост → остановка/сброс» согласован между моделью и экраном.

## 7. Эксперимент «сломайте и исправьте»

Баг предлагает: «Давайте просто выберем любую клетку». На обычном поле ошибка может долго не проявляться. У нас есть подготовленная позиция, где результат станет однозначным.

![Баг предлагает случайную клетку без фильтра, и еда ошибочно оказывается на хвосте почти заполненной змейки](/materials/mobile-lab/img/lab6/meme-01-apple-inside-snake.webp)

_Правильный вариант оставляет в списке только (15,0). Без фильтра первый элемент списка — занятая (0,0)._

### 7.1. Убираем только фильтрацию

В **`snake_game.dart`**, внутри `_placeFood`, временно удалите **только**:

```dart
        if (snake.contains(position)) {
          continue;
        }
```

`freeCells.add(position)`, обход всех координат, проверку пустого списка и выбор случайного элемента оставьте. Остальные правила роста не меняйте.

### 7.2. Получаем предсказуемую ошибку

Выполните **тот же готовый тест**:

```bash
flutter test test/snake_game_test.dart --plain-name "После роста остаётся одна свободная клетка"
```

Он должен упасть: ожидалась еда `(15, 0)`, а фактическая координата — `(0, 0)`.

Почему результат не зависит от удачи? `FirstRandom` всегда выбирает нулевой элемент. После удаления фильтра список содержит все клетки от `(0, 0)`, а не только свободную `(15, 0)`. Координата `(0, 0)` входит в подготовленное тело как хвост и при росте не удаляется.

Ошибка наблюдается в данных: еда оказывается внутри тела. Нельзя считать генератор правильным только потому, что на обычном разреженном поле картинка некоторое время выглядит нормально.

Не исправляйте тест, seed или ожидаемую клетку под неправильный алгоритм. Не коммитьте эту версию и не ждите случайного наложения в долгой ручной игре.

## Как восстановиться, если отстали

Сохраните личные файлы в резервной копии или согласованной ветке. Не начинайте GameBox заново и не заменяйте общие данные ПР4.

1. **Рабочая ПР5.** Восстановите свой checkpoint с движением, одним таймером, направлениями и lifecycle. Проверьте их отдельно от еды.
2. **Фиксированная еда.** Перенесите модель 2.2 и изменения экрана 2.3–2.5. Начальное `food = GridPosition(8,9)` позволяет увидеть цель рядом.
3. **Один шаг на еду.** Заполните сравнение по 3.2; будущая голова справа совпадает с food.
4. **Рост.** Восстановите условие сохранения хвоста по 3.3; после шага четыре координаты.
5. **+10.** Вставьте начисление по 3.4, проверьте 10 и сброс в 0.
6. **Случайность.** Добавьте импорт/конструктор/поле по 4.2, метод и фильтр по 4.3. В конце reset верните вызов `_placeFood` по 4.4.
7. **Почти полное поле.** Восстановите тестовый файл по 5.2, своё имя импортов и проверку 5.3. Запустите девять сценариев.

Если порядок операций потерялся, замените **метод `step` целиком** готовым итоговым вариантом:

```dart
  bool step() {
    if (phase != SnakePhase.running) return false;
    final next = requestedDirection;
    final newHead = _nextHead(next);
    if (!_inside(newHead)) {
      phase = SnakePhase.edgeStopped;
      requestedDirection = direction;
      return false;
    }

    final ateFood = newHead == food;
    direction = next;
    snake.insert(0, newHead);
    if (!ateFood) snake.removeLast();
    if (ateFood) {
      score += 10;
      _placeFood();
    }
    requestedDirection = direction;
    return true;
  }
```

Если повреждён генератор, замените **метод `_placeFood` целиком**:

```dart
  void _placeFood() {
    final freeCells = <GridPosition>[];
    for (var row = 0; row < size; row++) {
      for (var col = 0; col < size; col++) {
        final position = GridPosition(row, col);
        if (snake.contains(position)) {
          continue;
        }
        freeCells.add(position);
      }
    }
    if (freeCells.isEmpty) {
      food = null;
      phase = SnakePhase.filled;
      return;
    }
    food = freeCells[_random.nextInt(freeCells.length)];
  }
```

Этот вариант требует импорт `dart:math` и конструктор с полем `_random` по 4.2. Не оставляйте две версии метода. Остальную модель берите из 2.2, а итоговый reset завершайте `_placeFood()`, без фиксированной еды.

После восстановления выполните анализ и все тесты, затем коротко проверьте экран. Собственные значки или клавиатуру возвращайте после обязательной логики, не копируя ошибочный старый файл целиком.

## Перед следующей работой
